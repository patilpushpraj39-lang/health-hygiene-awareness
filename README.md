# EverydayWell — Health & Hygiene Awareness

A responsive CEFP student website focused on practical health and hygiene education.

## Features

- Six searchable topics: clean hands, drinking water, food care, surroundings, personal care and well-being.
- Interactive five-step handwashing guide.
- Fourteen daily commitments with browser-local progress and CSV download.
- Six-question awareness quiz with explanations.
- Five-slide presentation mode for an oral examination.
- Downloadable single-file offline website and relevant reference PDF pages.

## Run locally

Open `index.html` in a modern browser, or serve this folder with `python -m http.server 8000`.
No dependency installation or build step is required.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.

## Data and scope

Checklist progress is stored only in the visitor’s browser using localStorage. There is no backend, user registration, analytics or collection of personal health data. The quiz is educational and does not assess medical health.

WHO information supports the central messages. No field survey, measured awareness session, pre/post test or follow-up health measurements are claimed.

The reference PDF includes only the two relevant health and hygiene pages from the report.
